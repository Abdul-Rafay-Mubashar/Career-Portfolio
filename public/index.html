"An AI-Powered Smart POS Ecosystem for Intelligent Retail Operations"

Tech Used

React
Electron.js
Node.js
Whisper
Mongo db

In developing the Smart POS System, I was responsible for designing and implementing a complete AI-powered retail management platform that combines intelligent billing, inventory management, face authentication, and advanced reporting. The system was built using React.js and Electron.js for the desktop application, Node.js and Express.js for backend services, FastAPI for AI-powered functionalities, and MongoDB for scalable data storage. A major focus of the project was the integration of artificial intelligence into everyday POS operations. I developed a Voice Intelligence System using Whisper AI and Large Language Models (LLMs), enabling users to add products to invoices through natural voice commands. Voice input is converted into structured product information and automatically processed within the billing system, creating a faster and more efficient workflow. To improve product discovery, I implemented a Hybrid AI Search Engine that combines fuzzy matching and embedding-based vector search. This allows the system to accurately identify products even when names are misspelled, incomplete, or described differently. Product embeddings are automatically generated and synchronized through FastAPI services, enabling semantic search capabilities across the platform. On the backend, I developed core modules for billing, inventory management, authentication, and reporting. The billing engine supports real-time invoice generation, product management, quantity and price updates, invoice history tracking, and PDF invoice generation. The reporting system provides daily, weekly, monthly, and custom date-range analytics to help businesses monitor performance and sales trends. Security was enhanced through JWT authentication, bcrypt password hashing, and a Face Recognition Authentication System. Users can securely access the platform using either traditional credentials or biometric facial recognition, providing both convenience and security. Additionally, I contributed to the development of a React Native mobile application that allows business owners to remotely monitor sales, view reports, search invoices, download PDFs, and access analytics through secure biometric authentication. Overall, this project demonstrates my expertise in full-stack development, AI integration, desktop application development, backend architecture, biometric authentication, and scalable system design, resulting in a modern and intelligent POS ecosystem.

MedCall AI

"AI-Driven Healthcare Automation System for Smart Query Routing and Seamless Appointment Booking"

Tech Used

FastAPI
Twilio
Postgress SQL
Vecter db
Chroma db
OpenAI LLM

In developing this AI-Powered Healthcare Voice Automation Ecosystem, I was responsible for designing and implementing two interconnected yet independently functional systems: an AI Medical Assistant for intelligent query handling and a Voice-Based Appointment Booking System for automated scheduling. The solution was built using FastAPI, OpenAI GPT models, Twilio, PostgreSQL, and ChromaDB, creating a scalable and production-ready healthcare automation platform. The first system, the AI Medical Assistant, was designed using a Tree-Based Retrieval-Augmented Generation (RAG) architecture. Hospital knowledge was organized into a hierarchical structure consisting of hospitals, departments, doctors, and appointment information. Instead of relying on unrestricted LLM-generated responses, the system uses Large Language Models primarily for intent classification, entity extraction, query routing, and context understanding. Relevant information is retrieved from a vector database using semantic search and metadata filtering, ensuring that responses remain accurate, context-aware, and grounded in verified hospital data. To further improve retrieval accuracy, I implemented a context-aware query rewriting layer that leverages conversation history and contextual information to refine ambiguous user queries before retrieval. This significantly improves response precision and enables the system to handle real-world conversational interactions more effectively. The second system is an AI-Powered Voice Appointment Booking Platform that automates the complete appointment scheduling process through phone calls. Rather than functioning as an open-ended chatbot, the system utilizes an LLM as a controlled decision engine combined with a state machine architecture. User responses are classified into predefined categories, enabling structured conversation flows and reliable execution of booking operations. The booking workflow includes appointment intent confirmation, natural language date processing, doctor availability validation, slot retrieval, slot selection, and transaction-safe appointment creation. Backend APIs interact with the scheduling database while slot-locking mechanisms prevent double bookings and ensure data consistency. Upon successful booking, the system automatically provides voice confirmation and notification services. A key architectural achievement was the seamless integration between the Medical Assistant and the Appointment Booking System. When the Medical Assistant detects appointment intent during a conversation, it intelligently transfers the interaction to the booking workflow while preserving relevant doctor and department context. This creates a smooth end-to-end experience that guides users from information discovery to successful appointment scheduling within a single phone call. Overall, this project demonstrates my expertise in AI-powered voice systems, Retrieval-Augmented Generation (RAG), vector databases, Large Language Models, backend architecture, conversational AI, workflow automation, and scalable healthcare solutions, resulting in a reliable and intelligent healthcare voice automation ecosystem.

Vue
FastAPI
Postgress
Bootstrap
Playwright
Gologin Browser

Our LinkedIn Sales Navigator Scraper provides an intelligent and automated solution for extracting valuable business insights from LinkedIn. Designed for efficiency and scalability, the platform processes both person (PURLs) and company (CURLs) links, delivering accurate, structured data directly into the database. The system enables users to create and manage campaigns by uploading URL files along with campaign details such as name, type, and status (Pending, Scheduled). Each campaign can be paused, interrupted, edited (if pending), or deleted, user can also change pending status to inProgress giving users full control over their scraping workflows. Campaign results are securely stored in the database and can be conveniently downloaded in CSV format for further analysis or integration. With its streamlined interface and robust backend, the scraper ensures seamless handling of large-scale LinkedIn searches—such as finding professionals (e.g., Python developers) or exploring target companies. By automating data collection and campaign management, it minimizes manual effort while maximizing accuracy and productivity. This feature-rich, dynamic solution empowers businesses, recruiters, and sales professionals to optimize lead generation, track campaigns effectively, and unlock the full potential of LinkedIn Sales Navigator.
